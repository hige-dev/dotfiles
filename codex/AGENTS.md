# 作業ルール

## 言語

- コードコメント、READMEや各種ドキュメント、画面表示、ログ、エラーメッセージなど、人が読む文章はすべて日本語で記述する。
- 外部仕様で指定された固定文字列や、コード上の識別子など、英語表記が必要なものは原文を維持する。

## 検証

- コード、スクリプト、設定、またはプロジェクトの動作を新規作成・変更したら、完了前に関連するテストを実行する。
- 自動テストがない場合は、変更した動作を確認できるスモークテストや適切な検証を実施する。
- 実行した検証コマンドと実際の結果を報告する。環境の制約で実行できない場合は、原因を調べ、確認できなかった点を明記する。
